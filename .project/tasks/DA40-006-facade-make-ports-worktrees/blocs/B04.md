# B04 — Correctif de revue des préflights enfants

Statut : terminé le 2026-09-06.

## Défaut

`dev` exécutait correctement un préflight global, mais les recettes enfants `dev-server` et `dev-app` contrôlaient ensuite toutes deux les deux ports. Après le lancement du backend par `dev`, `dev-app` pouvait donc refuser le port backend légitimement occupé par son frère.

## Correction

`PORT_PRECHECK` accepte maintenant la liste de ports à contrôler :

- `preflight-ports` et `dev` : backend et UI ;
- `dev-server` : backend seulement ;
- `dev-app` : UI seulement.

## Preuve non destructive

Les expansions `make -n dev-app`, `make -n dev-server` et `make -n dev` ont été analysées : elles contiennent respectivement `for port in 4440`, `for port in 4140` et `for port in 4140 4440`. `make preflight-ports`, `DRY_RUN=1 make dev`, l'absence de listeners 4140/4440 et `git diff --check` sont verts. Aucun serveur n'a été lancé, arrêté ou laissé actif.
