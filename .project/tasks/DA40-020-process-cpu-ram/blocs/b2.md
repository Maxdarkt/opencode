# B2 — Client généré

`bun run generate` dans `packages/client`. `MakeDevStatusOutput`, `MakeDevStartOutput` et `MakeDevStopOutput` portent `cpuPercent?` et `rssBytes?`. Aucune édition manuelle de `src/generated`.

`bun typecheck` : client, protocol, core — pass. `check:generated` voit le diff attendu de ces champs, non commité. Une seconde génération ne dérive pas.
