# B2 — Libellé sur le catalogue affiché

Le formulaire du fournisseur personnalisé est une méthode clé. Il affiche `API` à côté du titre, via `billingChannel("key")`. Pas d’oauth sur ce formulaire.

Les lignes `key` / `oauth` du dialogue de connexion gardent leur libellé. Le sélecteur de modèle n’affiche le canal que s’il est unique.

Les autres locales reprennent les chaînes anglaises `API` et `abo`, pour que la parité i18n reste verte.
