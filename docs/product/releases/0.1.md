# Release 0.1 — Première tâche fiable

Cible approuvée le 2026-09-06 ; non livrée, sans date de publication engagée.
Pilote local macOS/web, une route serveur/session qualifiée. Une release signifie un résultat accepté ; aucun tag ou déploiement implicite.

## Résultat et critères de sortie
1. Version servie, révisions testées, dépendances, client/route et procédure reproductible identifiés.
2. Navigation et confirmation séparées ; chemin réel visible ; annuler/ouvrir sans initGit implicite.
3. Branche/HEAD/base, disponibilité et limites de revue explicites ; historique consultable distinct de fichiers disponibles.
4. Carte MT, dossier APEX, Session/Location et checkout concordants ; un propriétaire écrivain exclusif, refus sur incohérence.
5. Reprise relisant autorités et effets ; incertitude d’outil/PTY interdit réattribution.
6. Baseline dirty héritée préservée, diff attribué à la tâche, aucune remise à zéro implicite.
7. Phases APEX et statut MT distincts ; enfant review, parent done ; pilote consultatif.
8. Sous-total de coût mesuré/estimé/partiel/inconnu honnête ; aucun faux zéro ni restant inventé.
9. Checks et recette parent sur la version candidate exacte ; aucun défaut critique d’identité/exclusivité ouvert.

## Limites et dettes héritées
Pas de parallélisme, opérations Git sensibles automatiques, réparation mutatrice des anciennes sessions, ledger complet/plafond strict, routage économique, campagne payante, navigateur ou distribution multi-OS.
[Dettes M0](/Users/leanbot/Documents/40_Daidalon/features/40-tooling/.project/tasks/DA40-001-gap-analysis-m0/debts.md) : D01/D04 identité et modèle papier → critères 4–6 ; D02 coûts → information honnête, ledger différé ; D03 environnement → Sprint 1 puis recette ; D05 maintenance → mesurer après deux intégrations futures autorisées ; D06 distribution → avant publication ; D07 capacités MT/extensions → qualification Sprint 1.
Maintenance 3–6 j/mois : hypothèse de dimensionnement, pas mesure.
